💡 计算机的 0 和 1 💡

我们在前面学了，数据在互联网上是以 0 和 1 传输的。

为什么计算机偏偏只认识 0 和 1 呢？用 1, 2, 3, 4, 5 不行吗？

因为计算机是由电子元件组成的。

🔌
通电（亮）
= 1
🔋
断电（灭）
= 0

电灯只有“开”和“关”两种状态，所以计算机只能用 0 和 1 来记录一切。

二进制：逢二进一

人类有10根手指，所以习惯了“逢十进一”（9后面是10）。

计算机只有两个“手指”（0和1），所以它的规则是：逢二进一！

十进制： 0, 1, 2, 3, 4, 5...

二进制： 0, 1, 10, 11, 100, 101...

注意：二进制里的“10”，并不是我们说的“十”，而是“二”！

怎么把 0 和 1 变成数字？

我们可以把 4 个灯泡排成一排，给它们规定固定的“分值”：

8   4   2   1

规则：灯亮代表 1，灯灭代表 0。
把亮着的灯泡对应的数字加起来，就是答案！

演示：0 1 0 1
(4号灯亮 + 1号灯亮)
= 4 + 1 = 5
